# AI 课程活动授权与模型治理

管理人工智能普惠培训的课程目标、讲师与机构资质、教材版本、练习数据来源、模型用途、隐私授权、活动场次与学习证明。

## 参与方与事实

主要参与方包括培训项目运营人员、讲师、政府和企业学员、隐私审核人员、合作机构。领域资料记录以下已经确认的事实：

- 香港计划推出超过二百项全民人工智能培训课程和活动
- 人工智能发展同时带来模型训练、跨境数据和隐私治理挑战
- 技能提升计划面向大量雇员和普通市民
- 讲师资格、模型版本、数据隐私与跨境使用边界来自不同合作方
- 治理状态由只追加事件日志重建，服务重启后可接续提醒与待复核事项

## 治理模型

服务以**只追加事件日志**为唯一事实来源（`src/course_governance.py`），当前状态由事件重放得到，业务规则不依赖可变数据库：

| 治理要求 | 实现方式 |
| --- | --- |
| 课程版本与教材 | 版本号严格递增，发布即冻结；模型升级只能产生新版本，记录合作方、模型标识、版本与用途、教材指纹 |
| 讲师/机构资质 | 登记资质有效期；发布版本、排课、确认结课三个时点均校验有效；机构退出后不能开展新活动 |
| 数据与隐私门禁 | 讲师可提交教材与数据范围，隐私负责人审核；提交人不得自审；跨境数据须明确批准 |
| 隐私授权 | 学员授权须覆盖场次全程；撤回授权暂停其相关未完成场次，记录保留并生成补救任务 |
| 风险影响范围 | `not_started` 只暂停指定版本尚未开始的场次；`explicit` 只影响明确列出的场次；已完成场次不能暂停，只产生补救任务 |
| 例外审批 | 请求人与利益相关方都不能审批自己的例外；数据类例外由隐私负责人审批，运营类由运营人员审批 |
| 教材泄露 | 隔离版本、暂停全部未完成场次、禁止再排新课，已完成记录保留并生成补救任务 |
| 学习证明 | 结课须讲师本人确认；证明快照课程版本、教材指纹、模型版本、授权及对应数据范围审核、讲师确认事件序号，签发后不可改写 |
| 重启接续 | `JsonlEventStore` 将事件追加落盘；重放后 `resume_after_restart()` 返回临期/过期提醒、待复核事项与补救任务；已通知提醒不重复 |

事件日志序号必须连续，重放时发现缺口会拒绝启动，避免在不完整历史上做治理决定。

## 目录

- `contracts/context.schema.json` — 领域资料结构
- `fixtures/context.json` — 不含真实身份信息的领域资料示例
- `fixtures/governance-events.jsonl` — 端到端示例生成的事件日志
- `src/ai_governance_context.py` — 读取和校验领域资料
- `src/course_governance.py` — 事件溯源课程治理服务
- `examples/demo_governance.py` — 可运行的端到端演示
- `tests/` — 领域资料与治理规则测试

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

运行端到端演示（重新生成示例事件日志）：

```bash
python3 examples/demo_governance.py
```

三条命令只读写仓库内文件，不需要连接外部业务系统。

# AI 课程活动授权与模型治理

管理人工智能普惠培训的课程版本、讲师资质、数据授权与学习证明。

## 参与方与事实

主要参与方包括培训项目运营人员、讲师、政府和企业学员、隐私审核人员、合作机构。领域资料记录以下已经确认的事实：

- 香港计划推出超过二百项全民人工智能培训课程和活动
- 人工智能发展同时带来模型训练、跨境数据和隐私治理挑战
- 技能提升计划面向大量雇员和普通市民

## 业务约束

- 课程版本
- 讲师资质
- 数据授权
- 活动暂停
- 证明可追溯

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/ai_governance_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。

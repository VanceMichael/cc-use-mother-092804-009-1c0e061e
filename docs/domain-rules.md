# 领域边界

管理人工智能普惠培训的课程目标、讲师与机构资质、教材版本、练习数据来源、模型用途、隐私授权、活动场次与学习证明。

## 领域规则

### 版本不可变

- 课程版本号严格递增，教材一经发布即冻结；模型升级（含模型版本、用途、合作方变更）只能产生新版本。
- 新版本的风险与暂停不触及旧版本的任何场次和证明。
- 已签发学习证明保存当时快照：课程版本、教材指纹、模型提供方/标识/版本/用途、学员授权及其数据范围审核、讲师与讲师确认事件序号；后续任何事件都不得改写。

### 资质门禁

- 讲师资质有有效期；发布课程版本、安排场次（按场次开始时间）、确认结课三个时点必须有效。
- 排课讲师必须与课程版本确认的讲师一致，结课须讲师本人确认。
- 合作机构退出后不能登记新讲师、发布新版本或安排新场次。

### 数据隐私与跨境

- 讲师可提交教材和练习数据范围；只有隐私负责人可以批准或驳回，提交人不得自审。
- 标记为跨境的练习数据必须在数据范围批准中获得明确的跨境许可，否则课程版本不能发布。
- 学员授权按练习数据来源逐一取得，有效期必须覆盖场次结束时间；撤回授权后相关未完成场次暂停，已发生记录全部保留。

### 风险与暂停的影响范围

- `not_started`：风险只暂停指定课程版本中尚未开始的场次。
- `explicit`：风险只影响明确列出的场次。
- 进行中场次可暂停；已完成场次不可暂停，只能登记风险并生成补救任务（含证明复核、学员通知、补修安排）。

### 例外审批的职责分离

- 例外申请人不得审批自己的申请。
- 列入利益相关方的人员不得审批该例外。
- 数据范围与跨境类例外由隐私负责人审批；讲师资质与场次安排类例外由运营人员审批。

### 触发式处置

以下三类事件都会暂停相关未完成活动、保留已发生记录并生成补救任务：

1. 学员取消授权；
2. 合作机构退出；
3. 发现教材含不应公开的资料（同时隔离教材版本，禁止再排新场次）。

### 可追溯与重启接续

- 唯一事实来源是只追加事件日志，序号必须连续；重放发现缺口时拒绝启动。
- 管理人员可凭证明编号追溯其课程版本、授权、数据范围审核与讲师确认。
- 服务重启后由事件重放重建全部状态，续办资质/授权临期与过期提醒、待复核事项和补救任务；已通知的提醒记录在案，不重复通知。

## 资料约束

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。事件日志中的标识一律使用示例编号（如 `ORG-DEMO`、`LRN-DEMO`），不记录真实身份。
